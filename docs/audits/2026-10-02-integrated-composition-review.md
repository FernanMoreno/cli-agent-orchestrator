Final cross-process acceptance additionally reproduced concurrent remote publication inserting the same terminal twice. Under concurrent regression load, coordinator startup also exposed a genuine deadline race: it added the approved budget to a later attachment time while integrity checked the durable journal start. A deterministic 1.2-second delayed attachment reproduced the refusal; the deadline now uses the exact durable journal start plus frozen budget in the same attachment transaction, preserving the existing tamper check. The retained native failure confirms the same cause before any revocation or second effect.

Full regression found a plugin subdirectory selector copying the entire repository, inconsistent advertised workflow defaults, an untyped prepared-store SQLite failure and a current OpenCode native model refusal misclassified as idle. These were corrected at their responsible boundaries. Historical fixtures were migrated to explicit private legacy workflow settings, real teardown incarnation rows, causal sequence results and the additive atomic-publication mode parameter; their original ordering, consent, event and preservation assertions remain.
