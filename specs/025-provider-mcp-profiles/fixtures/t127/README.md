# T127 diagnostic source archive

The response-probe source and its Node tests are portable. Run the tests from the repository root:

```sh
node --test specs/025-provider-mcp-profiles/fixtures/t127/response-probe/test_response_hook_probe.mjs
```

The default probe stays disabled without a valid explicit private binding. Its bounded Response clone and marker show hook capability only; the marker is not a tool-argument witness. It never replaces the original response.

`control/` is a byte-preserved forensic source snapshot of the separately staged T127 R4 experiment, not a portable runnable harness or production feature. The driver remains closed behind two flags and private-input checks. The Python files are stored as `.py.txt` to preserve the exact receipt-bound bytes as archival data, without treating them as executable repository modules. The snapshot pins the public phase fixture at historical source6ffaefdd and native2.0.18; copying it into this repository does not create a new native acceptance result.

The control's Python tests ran in the reviewed private staging tree. They require its private expectations, source-head binding, generated plugin workspace copies and other prepared inputs. They are not runnable as archived here. The binary, private expectations, namespace argv/allowlist, nested Git/workspace copies, credentials, caches, logs and run outputs are excluded. Do not enable the driver in the checkout. Any re-execution needs a fresh private root, reviewed source/binary/input bindings, empty runtime state, ownership and memory admission; old paths/hashes are not execution authority. A portable control harness requires a separate refactor.

`source-archive-sha256.json` identifies the copied source bytes. Public sanitized results and their limits live in [T127 validation](../../validation-t127.md). No real-provider, full8 or global acceptance follows from this archive.

R4 renders the entire native configuration through CAO’s pinned production writer using the generic flat-MCP route, both auth sources set to None, synthetic session/model inputs and the exact native grant after wildcard denial. The recipe and its source inputs are archived; the rendered configuration is separately hash-pinned. Semantic roundtrip was verified. The unused Go header entry is a writer default and does not select a Go model. Private offer diagnostics contain fixed presence/schema booleans and counts only.
