# T099 — Portable two-role native diagnostic coordination

Date: 2026-10-23. Scope: offline diagnostic component; no product runtime or live launcher integration.

T096 persisted a message but rejected the sender's own native reply for missing Unicode. Its sender-first failure left receiver observation count0. That record does not prove that a receiver reply existed. The private runner is unavailable, so its old execution/control flow was not reconstructed or credited as new evidence.

`fixtures/native_phase_observer.py` provides synchronous polling independent of sender acceptance. Each fixed scope binds terminal ID, expected completed sequence and native agent. The first poll favors receiver; subsequent polls rotate after each state read, so a slow pending receiver cannot consume every tick and starve sender. Each tick polls one pending role and grants at most3s across its state read, frames and at most one native probe; the absolute phase deadline remains the original pre-input start plus75s. Pending polls run no faster than4Hz. Neither failed acceptance nor observations can start a native turn or send another message.

Stale states remain pending; malformed/later counters are unavailable. Each completed role gets at most one output/capture/probe attempt, including error paths. Readers receive absolute deadlines and frame readers also receive the65537-byte CAP+1 ceiling. Returned frames above64KiB UTF-8 are rejected without truncation. Readers must enforce their own I/O allocation/deadline bounds: synchronous Python cannot preempt an uncooperative callback. A single non-reentrant caller and a coherent monotonic time domain are required; nonfinite/backward clocks fail before further I/O.

Only bounded typed native-probe fields enter snapshots. Unknown fields are discarded; malformed types/schema fail closed, and arbitrary reasons/classifications map to fixed codes. Raw frames remain local to one observation. Closing drops private scopes, configuration/target and reader references. Pending roles become `not_triggered_by_deadline`, not an inferred profile mismatch. Sanitized late shapes may remain useful diagnostics but have unavailable status/false timing witnesses and cannot pass the existing additional profile predicate.
