- [x] Historias priorizadas con escenarios verificables.
- [x] Requisitos identificados y criterios medibles.
- [x] Casos límite y dependencias explícitos.

- [x] Ninguna promesa de capacidad ilimitada o aceptación implícita.
- [x] Estado de implementación pendiente sin casillas ejecutadas ficticias.
