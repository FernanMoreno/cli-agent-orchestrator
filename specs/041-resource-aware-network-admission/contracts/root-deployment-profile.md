# Perfil confiable de despliegue Root

`models/root_deployment_profile.py::RootDeploymentProfile` usa JSON version1 estricto y frozen. Campos: signing_key_file, trust_file y policy_file (paths absolutos privados); scope imprimible/canónico; worker_footprint, child_footprint, command_footprint, startup_footprint y refresh_footprint (memory_bytes/cpu_millicores positivos, storage_slots0); timeout_s hasta30 y close_timeout_s hasta30. No claves inline, budget, observation, grant, argv, env ni callback en el JSON.

`load_root_deployment_profile(path)` lee explícitamente un archivo privado acotado y devuelve el modelo. `assemble_root_deployment(profile, *, bootstrap, owner, control, target, env, clock, python_executable=None)` es inerte: convierte footprints, copia env, construye el comando `python -m cli_agent_orchestrator.runtime_channel.root_control` con los paths/scope explícitos y entrega un RootDeploymentRuntime. No instala el router, abre SQL, inicia hilos/procesos o aporta financiación. Python executable pertenece al compositor confiable, no al perfil HTTP.

`security/private_root_configuration.py::ExternalRootSigner(signing_key_file, trust_file)` es inerte. Preflight/call leen archivos privados regulares y estables con límite16KiB; signer JSON exacto {version:1,key_id,private_key_base64}, semilla Ed25519 de32bytes base64 canónica, ID con el contrato existente. El trust JSON público conserva exactamente el codec de Root CLI. La clave pública derivada y el key_id deben coincidir; ausencia/permisos/schema/mismatch son error fijo sin path/entrada/causa privada. El supplier no genera, renueva, repara, cachea globalmente ni reutiliza claves peer.

`credential_preflight=None` conserva el flujo existente. Cuando se configura, el worker lo ejecuta bajo su cargo antes de su primer connect y antes de llamar al issuer; el supplier todavía se valida tras commit según contrato actual. Un fallo poscommit conserva record/handle/cargos. El perfil y la coincidencia signer/trust no prueban grant ni partición disjunta. La instalación productiva requiere esa autoridad externa independiente; ausente, el compositor no debe instalar el runtime ni convertir unknownstorage en capacidad.
